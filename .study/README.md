# ComprehensiveGS 学习记忆

这个目录保存与 Codex 讨论后需要跨会话保留的信息。目标是让后续工作能快速接上已有理解、决定和未完成事项。

## 文件职责

| 文件 | 用途 |
| --- | --- |
| `PROJECT_STATE.md` | 当前工程结构、已完成能力、已知缺口与验证状态 |
| `DECISIONS.md` | 长期设计/学习决定及其理由 |
| `OPEN_QUESTIONS.md` | 尚未决定、需要用户选择或运行验证的问题 |
| `sessions/YYYY-MM-DD.md` | 按日期追加的讨论结论、行动与证据 |

## 阅读顺序

1. 先读 `PROJECT_STATE.md`，建立当前全貌。
2. 再读 `DECISIONS.md`，避免推翻已经确认的选择。
3. 查看 `OPEN_QUESTIONS.md`，确认哪些内容仍不能当作定论。
4. 最后读最近的主题相关 session，了解推理过程和下一步。

## 记录原则

- 只记录“可继续工作的结果”，不保存逐字聊天。
- 结论必须尽量附源码路径、资产路径、控制台输出或 Git 提交作为证据。
- 推演结论与实测结论分开标注。
- 修改代码或资产后，同时记录验证方式；失败尝试也应记录原因，避免重复踩坑。
- 当前源码和用户最新指令始终高于旧记录。
